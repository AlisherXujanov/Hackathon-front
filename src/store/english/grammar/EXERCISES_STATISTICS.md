## 📝 Instructions for Creating Missing Files

### File Structure Requirements

Each exercise file must follow the JSON schema defined in `ExercisesSpec.md`:

1. **File Location**: `src/store/data/practice/language/english/grammar/exercises/{level}/{LEVEL}_{NUMBER}.json`
   - Example: `src/store/data/practice/language/english/grammar/exercises/a2/A2_043.json`

2. **File Naming Convention**:
   - Format: `{LEVEL}_{NUMBER}.json` (e.g., `A2_043.json`, `B1_006.json`)
   - Use uppercase for level (A1, A2, B1, B2, C1, C2)
   - Use zero-padded 3-digit numbers (001, 002, ..., 043, etc.)

3. **Exercise Distribution** (for 25 exercises per file):
   - **40%** multiple_choice (10 items: mc1, mc2, ..., mc10)
   - **40%** short_answer (10 items: sa1, sa2, ..., sa10)
   - **20%** multiple_gap_filling (5 items: mgf1, mgf2, ..., mgf5)

   **⚠️ CRITICAL:** Each file must have **at least 3** `multiple_gap_filling` exercises. The ideal is 5 for a 25-exercise file (20% distribution).

### Required Fields

Each JSON file must include:

```json
{
  "id": "{LEVEL}_{TOPIC_IN_UPPERCASE_WITH_UNDERSCORES}",
  "title": "{Human-readable topic title}",
  "items": [
    // Array of exercise items following the schema
  ]
}
```

### Exercise Type Requirements

#### Multiple Choice (`multiple_choice`)
- Question must be judgment-style: "Choose the correct sentence."
- Options must be complete sentences or phrases
- Exactly ONE correct answer
- All incorrect options must contain clear grammatical errors

#### Short Answer (`short_answer`)
- Only ONE gap per exercise: `"She ___ to school every day."`
- Provide clear context
- Include base forms in parentheses when needed for verb exercises

#### Multiple Gap Filling (`multiple_gap_filling`)
- Minimum 100 words of text
- 10-15 gaps numbered sequentially: `___1___`, `___2___`, etc.
- Text must be meaningful and engaging
- Cover the target grammar topic systematically

### Localization Requirements

- **MUST localize**: `question`, `prompt` objects (en, ru, uz)
- **DO NOT localize**: `options[].answer`, `answers[].answer`, `text` field
- **MUST include**: Explanations in all three languages (en, ru, uz)

### Quality Checklist

Before submitting any file, verify:

- ✅ Grammar follows authoritative English grammar rules (Cambridge, Oxford, Longman)
- ✅ Exactly ONE grammatically perfect answer per exercise
- ✅ All incorrect options contain clear, identifiable errors
- ✅ Vocabulary and complexity match the CEFR level
- ✅ Context is unambiguous
- ✅ All three languages (en, ru, uz) are included
- ✅ Exercise distribution matches 40/40/20 ratio (10 MC + 10 SA + 5 MGF for 25 exercises)
- ✅ **At minimum, 3 `multiple_gap_filling` exercises per file** (ideally 5 for 25 exercises)
- ✅ File follows naming convention exactly
